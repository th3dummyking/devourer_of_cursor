# devourer_of_cursor

## devourer of gods right on your screen lol ##


making for fun, run by just running the python program normally. You can run on terminal and it will work. The main file is  worm_overlay_2.pyw

**alt ctrl Q**          to make the worm die, work even while outside of the terminal.

**c + m**   chase mode  : allow the worm to follow the cursor with a somewhat curve trajectory

**w + m**   wander mode : the worm will now enter wandermode, in which it will just chill and go around the cursor. 

**R + M**   box mode    : the worm will now go in around the screen with a wave like path, configurable in the files at line 67 - 83

now also will have certain voice line spawn with shaking and effects config. The lines can be added or remove in dog_lines.txt
